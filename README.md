# FYP - Skill Bazaar

Skill Bazaar focuses on revolutionizing the current blue collar job marketplace by integrating automation and AI to build a platform where illiterate people can easily sell their services. It will tend to decrease unemployment caused by informal networks of word-of-mouth that limit job opportunities.
